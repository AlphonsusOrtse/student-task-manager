# Student Task Manager

A Python command-line project for organizing tasks and practicing core software engineering concepts, including input validation and JSON-based persistence.

## What This Project Explores

- Creating and managing tasks from a terminal interface
- Validating user input and handling invalid task IDs
- Saving and loading task data using JSON
- Organizing Python code into reusable functions
- Understanding the difference between in-memory state and persistent storage

## Tech Stack

- **Language:** Python 3
- **Storage:** JSON
- **Tools:** Git, GitHub, terminal

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AlphonsusOrtse/student-task-manager.git
cd student-task-manager
```

Explore the repository files for the application entry point and current implementation.

## Learning Goals

This project is part of my hands-on practice with Python fundamentals, debugging, error handling, and designing programs that retain data between runs.
